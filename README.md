# Lumen Studio -- Agency Landing Page

A single-page, responsive landing page for a fictional design agency. Pure HTML/CSS/JS, no build step, no dependencies.

## Sections

Hero, stats bar, services, selected work grid, about/testimonial, and a contact form (front-end only -- wire the `onsubmit` handler in `index.html` up to your own backend or a form service like Formspree to make it functional).

## Running it

Just open `index.html` in a browser, or serve the folder with any static file server:

```bash
npx serve .
```

## Deploying

Works as-is on GitHub Pages, Netlify, Vercel, or any static host -- no build step required. For GitHub Pages: repo Settings -> Pages -> Deploy from branch -> `master` / root.
